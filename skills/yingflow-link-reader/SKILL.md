# Links Reader

## Language

Respond in the user's language. If they write in Chinese, reply in Chinese; if English, English. Keep technical tokens (paths, flags, field names) in English.

## Links Read Workflow

```
- [ ] Step 0: 前置依赖检查
- [ ] Step 1: 收集内容&加工提炼
- [ ] Step 2: 整理输出
- [ ] Step 3: 输出内容&导入**obsidian知识库**
- [ ] Step 4: 清理
```

### Depends Tools

#### 浏览器工具

- 使用MCP工具：chrome-devtools-mcp

#### Obsidian

- 环境变量 OBSIDIAN_HOME : obsidian内容的根目录

### Step0: 前置依赖检查

检查 Depends Tools, 如果连接有问题或者不存在，则报错返回，不再执行

### Step1: 收集内容&加工提炼
必须使用**浏览器工具**进行获取内容进行分析和组织，具体结构如下：
- 深入理解阅读内容，形成全文总结，按原文顺序分点展开，每个要点对应文章的一个主要内容块，保留关键数据和细节，摘要篇幅控制在原文的 30%-40%
  - **覆盖全文**：按文章结构逐段提炼，不跳过任何段落的核心信息
  - **保留关键细节**：数据、时间、人名、地名、金额等具体信息必须保留，不得模糊化
  - **保留原文逻辑**：观点之间的因果、转折、递进关系必须在摘要中体现
  - **不添加观点**：只提炼作者表达的内容，不加入自己的判断或补充
- 具备批判性思维，能对观点进行分析评估
- 熟练运用 Markdown 语法，生成结构化的文本
- 根据 下面的「文档模板」, 进行内容组织， 其中列表的序号需要是1️⃣2️⃣3️⃣这种序号
星级:以专业级的运营角度，按照内容质量进行打分，最高5分。通过星星表示；例如五星：🌟🌟🌟🌟🌟
链接:原始的公众号链接 markdown格式
总结:对全文内容的摘要总结，虽然是摘要但是要全面，核心信息不能丢
观点:抽取文章内的观点，1-3个，如果文章没有明确的观点导向，留空。
金句:来源于内容内，1-2个。
问题:选取在这方面专业的人物，根据内容提出一个进一步思考的问题，加粗表示。例如 政治类的内容输出为：**康熙皇帝**:xxx
案例:从历史角度看，相似的事件。给出简要的时间、事件摘要
思维模式：按照 **第一性原理思维**，**系统性思维**， **逆向思维** 进行快速分析，干货不废话， 每个思维模式格式：🧠XX:XX ， 按照列表输出

### Step2: 整理输出

- 获取当前日期和时间

```bash
date +%Y%m%d_%H%M%S
```

- 输出样式要求：
根据 下面的「文档模板」
DATE 是 当前日期 YYYY-MM-DD格式
TAGS 是 内容标签；分析内容的核心要求，给出1-3个标签，例如AI，科技，社会，生活等等
TITLE 是 内容标题，根据标题和内容做简单的抽象，不要存在符号，字符不超过30字
SOURCE 是 内容原始链接，不更改
对模板内进行替换

#### 文档模板
---
date: {{DATE}}
tags: [{{TAGS}}]
---

# {{TITLE}} | {{DATE}}

> 来源：{{SOURCE}}

## 星级
内容...

## 总结
内容...

## 观点
内容...

## 金句
内容...

## 问题
内容...

## 案例
内容...

## 思维模式

- 思维1：xxx
- 思维2：xxx

---

*文档生成日期：{{DATE}}*

### Step3: 输出内容&导入**obsidian知识库**
1. 返回整理后的**金句** && **思维模式**核心观点给我，其他不需要给我
2. 整体内容通过markdown文档保存，文件名称遵循如下规范：YYYYMMDD_HHMMSS_{来源}_{标题}.md

| 来源域名 | 名称 |
|---------|------|
| mp.weixin.qq.com | 微信 |
| m.toutiao.com | 头条 |
| 其他 | 其他 |

3. 保存路径：$OBSIDIAN_HOME/0-Inbox/YYYY-MM 目录下，其中YYYY-MM是当天日期

### Step4: 清理
1. 成功完成上述流程后，关闭刚才打开的浏览器Tab页。**但是不要关掉浏览器，保持浏览器开启**
